🚀 GETTING STARTED
------------------

1. Install Python packages:
   pip install -r requirements.txt

2. Get Google credentials (10 min setup):
   • Follow CREDENTIALS_SETUP.md step-by-step
   • Download credentials.json from Google Cloud
   • Put it in this folder

3. Verify setup:
   python setup_check.py

4. Test it out:
   python add_company.py "Stripe" --tracker fintech

5. Open your Google Sheet to see it appear!

📚 QUICK REFERENCE
------------------

Add companies:
  python add_company.py "Company Name" --tracker fintech

Research contacts:
  python find_contacts.py "Company Name" --tracker fintech

Update contact:
  python update_status.py "Company Name" --tracker fintech \
    --contact "Jane Doe" --title "UX Designer"

Update status:
  python update_status.py "Company Name" --tracker fintech \
    --status "Reached Out"

View info:
  python update_status.py "Company Name" --tracker fintech --show

💡 HOW IT WORKS
---------------

1. Scripts connect to Google Sheets using the API
2. You run commands from terminal
3. Data gets added/updated in your sheets automatically
4. You can still edit sheets manually - everything syncs!
